## ⚙️ How to run

```bash
git clone https://github.com/SubhashAndroidDev/30-days-of-python.git
cd 30-days-of-python
uv run day_01/main.py
```

To run any other day, change the path:

```bash
uv run day_02/main.py
uv run day_03/exercises.py
```
