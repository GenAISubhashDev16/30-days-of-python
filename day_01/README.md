# Day 01: Introduction to Python

## 📖 What I Learned
- What Python is and why it's popular
- Installing Python and setting up VS Code
- Running code in the Python shell and as `.py` scripts
- Basic syntax: indentation, comments, `print()`
- Data types: int, float, complex, str, bool, list, tuple, set, dict
- Checking types with `type()`

## 📁 Files
| File | Description |
|------|-------------|
| `main.py` | Examples of printing, arithmetic and data types |
| `exercises.py` | Solutions to Day 1 exercises |

## ▶️ Run
```bash
python main.py
python exercises.py
```

## 💡 Key Takeaways
- Python uses **indentation** to define code blocks.
- Use `#` for comments.
- `type()` tells you the data type of any value.
