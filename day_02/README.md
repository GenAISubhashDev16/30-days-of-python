# Day 02: Variables, Built-in Functions & User Input

## What I Learned
- Python built-in functions: `print`, `type`, `len`, `input`, `round`, `abs`, `max`, `min`, `sum`
- Declaring variables and the naming rules (snake_case)
- Multiple assignment in a single line
- Type casting with `int()`, `float()`, `str()`
- Reading user input with `input()` (always returns a string)
- Using f-strings to format output
- Area and circumference of a circle

##  Key Takeaways
- A variable name cannot start with a number or contain spaces/hyphens.
- `input()` returns a `str`, so convert it before doing math.
- `len()` works on strings and collections.
- f-strings (`f"Hello {name}"`) are the cleanest way to print values.
