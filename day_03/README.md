# Day 03: Booleans & Operators

## 📖 What I Learned
- Boolean values: `True` and `False`
- Truthy and falsy values (`0`, `""`, `[]`, `None` are falsy)
- Assignment operators: `=`, `+=`, `-=`, `*=`, `/=`, `**=`
- Arithmetic operators: `+ - * / // % **`
- Comparison operators: `== != > < >= <=`
- Logical operators: `and`, `or`, `not`
- Identity (`is`) and membership (`in`) operators
- Chained comparisons like `0 <= x <= 10`

## 💡 Key Takeaways
- `=` assigns a value, `==` compares values.
- Comparison operators always return a boolean.
- `and` needs both sides True, `or` needs at least one.
- Use `is None` (not `== None`) to check for None.
